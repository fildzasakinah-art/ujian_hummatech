# CloudLaundry
Ini adalah proyek untuk ujian hummatech

## Fitur Utama
- Fitur 1: Login ( tanpa database)
- Fitur 2: Registrasi (tanpa database)
- Fitur 3: Pesan Online ( mengurangi resiko antri panjang)

## Teknologi yang Digunakan
- HTML 
- CSS
- JavaScript
- PHP

## Cara Menjalankan Proyek
Proyek yang saya buat ini menggunakan bahasa pemograman PHP, sehingga untuk membukanya
membutuhkan local server seperti XAMPP

1. **Clone atau Unduh Repository:**
   Unduh proyek ini dan pastikan folder proyek bernama `UJIAN_HUMMATECH`.

2. **Pindahkan ke Folder htdocs:**
   Pindahkan atau salin folder `UJIAN_HUMMATECH` ke dalam folder server lokal Anda (jika menggunakan XAMPP, letakkan di `C:/xampp/htdocs/`).

3. **Jalankan Apache Server:**
   Buka XAMPP Control Panel, lalu klik **Start** pada bagian **Apache**.

4. **Akses Melalui Browser:**
   Buka browser Anda, lalu ketik dan buka URL berikut:
   ```text
   http://localhost/UJIAN_HUMMATECH/index.php
